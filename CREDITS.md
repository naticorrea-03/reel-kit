## Notes

- Only the Pixabay summary page was read for the Pixabay license. The full Terms of Service are the binding text.
- Font licenses were verified by finding `OFL.txt` next to each family in the google/fonts repo. Each family's `OFL.txt` ships in `licenses/`.
- Apache-2.0 asks for the license text and a notice of changes if you redistribute HyperFrames code. We install it through npm and do not vendor it. The four ported carousels carry the license text and a list of changes in `licenses/`.
